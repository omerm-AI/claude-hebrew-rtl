# איך זה עובד: עברית מימין לשמאל ב-Claude Code

חומר רקע לפוסט. הכול כאן נבדק בפועל, ומה שלא נבדק מסומן.

## הבעיה

- Claude Code כותב עברית מצוינת, אבל מציג אותה כמו אנגלית.
- באפליקציית המחשב הטקסט נדחף לצד שמאל, והנקודה בסוף המשפט קופצת לצד הלא נכון.
- משפט שמשלב עברית ואנגלית מתבלגן, וצריך לפענח אותו.
- בטלפון הפסקאות מיושרות, אבל הבולטים והמספרים יושבים בצד שמאל.
- זה מאמץ קטן בכל שורה, שמצטבר לאורך יום עבודה.

## מה מאפשר את הפתרון

- ל-Claude Code יש יכולת חדשה שנקראת mod: תוסף קטן שמשנה את Claude עצמו, ולא רק את מה שהוא כותב.
- mod יכול לשנות איך תשובה מצוירת על המסך, ויכול לגעת בתשובה רגע לפני שהיא נשמרת.
- את ה-mod הזה Claude כתב בעצמו, בשיחה אחת, כולל בדיקות.

## שני מסכים, שני פתרונות

אותה שיחה מוצגת במחשב ובטלפון, וכל מסך מתנהג אחרת. לכן יש שני מנגנונים.

### במחשב: ה-mod מצייר את התשובה מחדש

1. לפני שהתשובה מופיעה, ה-mod מפרק אותה לשורות: כותרת, פסקה, בולט, מספור, ציטוט.
2. כל שורה מפורקת למילים, והמילים מסודרות מימין לשמאל.
3. כשהשורה ארוכה מדי, היא נשברת בין מילים, והשורה הבאה מתחילה שוב מימין.
4. מילים רצופות באנגלית, כמו Claude Code, נשארות יחד ובסדר הנכון.
5. קוד ופקודות נשארים משמאל לימין, כי כך קוראים אותם.

למה צריך לפרק למילים: האפליקציה מתעלמת מההוראה הרגילה "הטקסט הזה מימין לשמאל". היא כן מכבדת סידור של פריטים בשורה. לכן כל מילה הופכת לפריט.

### בטלפון: ה-mod מסדר את הטקסט לפני שהוא נשמר

1. אפליקציית הטלפון לא מקבלת ציור מ-mod. היא מציגה את התשובה השמורה בדרך שלה.
2. לכן ה-mod פועל שלב אחד קודם: רגע לפני שהתשובה נשמרת בשיחה.
3. כל בולט ומספר הופך לשורה רגילה שנפתחת בסימן כיוון בלתי נראה, עם הבולט או המספר שלה.
4. שורות סמוכות מתחברות לקטע אחד, כך ששורה ארוכה אחת מושכת לימין גם את הקצרות.
5. בסוף קטע קצר ובסוף כותרת נוסף ריפוד בלתי נראה, שמותח אותם לכל רוחב המסך.

התוצאה בטלפון: בולטים, מספרים, שורות קצרות וכותרות גדולות יושבים בצד ימין.

## איפה לא צריך כלום

- בדפדפן ובלשונית Cowork העברית מיושרת גם בלי התקנה.
- כך זה נראה בבדיקה שלנו, בלי שהותקן שם דבר.

## ההתקנה

1. דרך אחת: להוסיף את התוסף לחשבון ב-claude.ai, בכמה לחיצות. זה מכסה גם שיחות ענן.
2. דרך שנייה: להדביק ב-Claude Code שורה אחת עם קישור לריפו.
3. בדרך השנייה Claude מוריד את התוסף, קורא את קובץ ההתקנה, מתקין ובודק את עצמו.
4. בסוף מופיעה שורה אחת: הצליח, או קוד שגיאה עם הסבר מה לעשות.
5. כחמש דקות, בלי ידע טכני.

## כמה זה עולה בטוקנים

- הציור במחשב לא עולה טוקנים. הוא רץ על המחשב ולא פונה למודל.
- התיקון לטלפון מוסיף לכל תשובה שמורה כמה תווים בלתי נראים, והמודל קורא אותם שוב בהמשך השיחה.
- התוספת קטנה, והריפוד נוסף רק לקטעים קצרים. היא לא נמדדה במדויק.

## מה חשוב לומר ביושר

- זה עובד ב-Mac, בשיחות Code של אפליקציית Claude.
- בטלפון זה נבדק ב-Android. באייפון לא נבדק.
- בטלפון השינוי חל על תשובות חדשות בלבד.
- כדי ליישר בטלפון, התשובה נשמרת עם סימנים בלתי נראים. בטקסט שמעתיקים מתשובה ייתכנו רווחים בסוף שורה.
- החלקים הקבועים של האפליקציה לא משתנים: סרגל צד, תפריטים, תיבת ההקלדה.
- Windows לא נתמך כרגע.
- הכול רץ על המחשב של המשתמש. ההתקנה מורידה רק את קוד התוסף מ-GitHub, ולא שולחת מידע לשום מקום.
- בשיחות שרצות בענן התוסף פועל רק אם מתקינים אותו לחשבון ב-claude.ai, ולא רק למחשב. שם הוא מסדר את הטקסט לפני השמירה, בלי ציור.
